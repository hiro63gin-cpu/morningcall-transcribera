## 1. 市場概況：原油高とフランス不安が同時進行

NAB Morning Callでは、前夜の市場について「終値だけを見ると、実際の値動きの激しさを過小評価している」と説明している。投資家は、次の二つのリスクショックの間で揺れているという整理である。

1. **地政学リスクによる原油高**
2. **フランスの政治・財政問題による国債スプレッド拡大**

### 主要市場の水準

- 米ドル：前日比約0.25%下落
- 豪ドル：0.3%上昇し、1豪ドル＝0.70米ドルをわずかに上回る水準
- 米10年国債利回り：3bp低下
- ドイツ10年国債利回り：5bp低下
- フランス10年国債利回り：1bp低下
- 豪州10年国債利回り：前日に5.25%まで上昇し、その近辺で推移
- ブレント原油：0.75%下落し、108.70ドル前後
- WTI原油：小幅安で103.50ドル前後
- S&P 500：0.4%上昇
- NASDAQ：0.25%上昇
- ダウ平均：1%上昇
- Euro Stoxx 50：0.4%下落
- CAC 40：0.4%下落
- FTSE 100：0.3%下落

**投資上の意味合い：**  
原油高は、ガソリン・輸送・生産コストを通じてインフレを押し上げる。その結果、中央銀行の利下げ期待が後退し、債券利回り上昇、金利感応度の高い住宅・成長株への下押し圧力につながる。一方、地政学リスクが深刻化すれば、安全資産として米国債や米ドルが買われる可能性もあるが、今回は米ドルが小幅に下落しており、単純なリスク回避相場ではない。

## 2. 原油：一時110ドル、イラン・米国協議への期待が後退

ブレント原油は夜間に106～110ドルのレンジで取引され、一時ほぼ112ドルまで上昇した。これは約5カ月ぶりの高値である。その後は上げ幅を縮小し、108.70ドル前後まで戻している。WTIも103.50ドル近辺で推移した。

原油上昇の背景には、イランと米国がカタールおよびパキスタンの仲介で合意に近づくとの期待があった。しかし、NABの説明では、協議は進展していないようである。イランは少なくとも米国の中間選挙までは時間をかける構えで、米国大統領の支持率に悪影響を与える緊張状態を維持する可能性があるとの見方が紹介された。

**NAB側の見立て：**  
協議が進まない限り、地政学的な供給不安が原油価格を高止まりさせやすい。夜間の価格レンジが広かったことからも、ヘッドラインに対する市場の反応が非常に大きい状態にある。

**価格への波及経路：**

- 原油高 → エネルギー・輸送・製造コスト上昇
- インフレ高止まり → 中央銀行の利下げ時期後ずれ
- 国債利回り上昇 → 株式のバリュエーション低下
- 家計の燃料負担増加 → 可処分所得と消費の圧迫
- エネルギー株には追い風だが、消費関連株や輸送株には逆風

## 3. フランス：OAT-Bundスプレッドが154bpへ拡大

フランスでは、政治・財政を巡る不安と抗議活動が続いている。政府は群衆の統制を目的に軍を投入するとしており、週末にはさらなる暴動が予想されている。夜間には外出禁止令（curfew）の導入が投資家の不安を一部和らげたとの見方もあったが、国債市場ではフランス資産からの資金流出が続いた。

10年OAT-Bundスプレッドは150bpを上回り、一時154bpまで拡大した。

- 前週末：約138bp
- 数週間前の高値：約159bp
- 今回の夜間高値：154bp

これは、フランス国債の利回りがドイツ国債に対して急速に上昇していることを意味する。

**NAB側の見立て：**  
フランスの状況が改善しなければ、スプレッドはさらに拡大する可能性がある。現時点では、フランスの金融市場からのポジション解消が中心で、他市場への波及はまだ限定的とされている。Bessent氏も、フランス情勢からの波及（spillovers）は予想していないと発言した。

**価格への波及経路：**

- フランス国債の信用・政治リスク上昇 → OAT利回り上昇、価格下落
- 銀行・保険会社などフランス金融株への売り
- 欧州の財政リスク再評価 → 周辺国国債やユーロへの波及リスク
- ただし、現段階では米国債など他市場への広範な波及は確認されていない

## 4. 債券：高い利回りが投資家を呼び戻す

米10年国債利回りは夜間に5.07～5.13%のレンジで推移し、最終的には3bp低下した。ドイツ10年債は5bp、フランス10年債は1bp低下した。

NABは、利回り水準が高くなったことで、投資家が債券市場に戻り始めていると説明している。最近の米国債入札でも需要が確認され、さらに日本の20年国債入札では過去最高の需要となった。

- 日本20年国債の応札倍率（bid-to-cover ratio）：5.84倍
- 前回入札：4.01倍

この結果は、日本の投資家が海外資産から国内へ資金を戻す動き、すなわち資本の本国回帰（capital repatriation）の兆候とも整合的である。

**価格への波及経路：**

- 高い債券利回り → 債券のインカム魅力が上昇
- 債券需要の増加 → 利回り上昇を抑制、価格を下支え
- 一方、利回りが高止まりすると株式の割引率が上昇し、特に高PERの成長株に逆風
- 日本からの資金還流が進めば、海外債券・株式への需要や為替にも影響する可能性がある

## 5. 株式・AI関連：米国株は業績期待で持ち直す

欧州株は軟調だったが、米国株は取引後半に回復した。S&P 500構成銘柄では、終盤に約400銘柄が上昇したと説明されている。米国株はグローバル株式市場を上回った一方、NASDAQは相対的に弱かった。

個別では、

- CoreWeave：2%上昇
- Apple：0.7%下落
- Meta：2%下落

投資家の注目は引き続きAI分野と企業業績である。数時間後にはSpaceXの発表、翌日にはMetaの発表が予定されており、投資家はAI投資、クラウド需要、広告、収益成長の持続性を見極めようとしている。

**NAB側の見立て：**  
株式市場は、地政学や金利上昇リスクを抱えながらも、企業業績、とりわけAI関連の成長期待に支えられている。ただし、「期待先行」であるため、決算内容が期待に届かなければ、株価の反応は大きくなり得る。

**価格への波及経路：**

- AI投資・収益成長への期待 → 半導体、クラウド、データセンター関連株を押し上げ
- 高金利 → 将来利益の現在価値を低下させ、グロース株のPERを圧迫
- 決算が期待を上回る → AI関連株の再評価
- 期待未達 → 高いバリュエーションの巻き戻し

## 6. 欧州景気：ドイツZEWは低下、エネルギー高が重石

ドイツのZEW景気期待指数は、

- 前月：34.7
- 今月：28.1

へ低下した。4月以来初めて景況感が悪化した。

ZEWのAchim Wambach会長は、ドイツ経済は停滞から徐々に脱しつつあるものの、回復は自律的ではないと述べた。個人消費と投資は弱く、その背景にはエネルギー価格の高さがある。エネルギー高は実質所得を圧迫し、企業の生産コストを押し上げ、インフレをより長く高止まりさせる。

**価格への波及経路：**

- エネルギー高 → 実質所得低下 → 個人消費減少
- 生産コスト上昇 → 企業利益を圧迫
- インフレ長期化 → ECBの利下げ余地を縮小
- 欧州株・欧州債券にとって、景気減速と金利高が同時に逆風

## 7. 米国：住宅市場が大幅に悪化、高金利の消費への波及を警戒

米国の住宅関連指標は弱かった。

- 9月の中古住宅販売保留契約（pending home sales）：前年比12.6%減
- 前月比：7.3%減
- 市場予想：前月比0.5%減
- 9月の住宅着工件数：5%減
- 市場予想：2%増

住宅ローン金利の高さが住宅市場を圧迫している。Pantheonの推計では、既存の一戸建て住宅の中央値を新たに住宅ローンで購入する場合、毎月の返済額は平均的な税引き後所得の約40%に達する見込みで、年初の35%から上昇している。

**NAB側の見立て：**  
現時点では、米国消費者は貯蓄を取り崩すことで、住宅ローン負担の増加をある程度吸収している。しかし、住宅ローン金利の上昇が続けば、住宅資産の評価や家計の可処分所得を通じて、最終的に消費を抑制する可能性がある。

**価格への波及経路：**

- 住宅ローン負担増 → 住宅購入減少、住宅関連需要減少
- 可処分所得の減少 → 小売・サービス消費の鈍化
- 住宅市場の悪化 → 景気後退懸念、長期金利低下要因
- ただし、インフレが高いままだと中央銀行は容易に利下げできず、株式・住宅双方に複合的な圧力

## 8. 英国：失業率は低下、賃金圧力を理由に11月利上げ観測

英国では、失業率が4.9%から4.7%へ低下した。通常、利上げを望まない局面では失業率の低下は好ましくない材料であり、労働市場の逼迫を示す。

BoEのMegan Green氏は、賃金上昇圧力の緩和が止まったとして、11月初旬の次回会合で利上げすべきだと示唆した。民間部門の賃金上昇率は2.9%から3.0%へ上昇したと説明されている。音声はこのデータが市場予想と一致したとの説明途中で終了しているため、それ以上の数値やBoE全体の決定は示されていない。

**価格への波及経路：**

- 失業率低下・賃金上昇 → サービスインフレの粘着性を高める
- 利上げ観測 → 英国債利回り上昇、ポンドを下支え
- 金利上昇 → 英国住宅、消費、企業投資に逆風
- 賃金インフレが続けば、BoEの利下げ期待は後退しやすい

## 9. 豪州・RBA関連

豪ドルは0.3%上昇し、1豪ドル＝0.70米ドルをわずかに上回った。一方、豪州10年国債利回りは前日に5.25%まで上昇し、その水準近辺で推移している。

音声では、RBAの政策判断や具体的な利上げ・利下げ予想は示されていない。ただし、豪州の長期金利が5%台前半にあることは、国内インフレ、海外金利、財政・債券需給などを市場が意識していることを示す。

**価格への波及経路：**

- 豪州金利上昇 → 豪ドルの金利面での支援要因
- ただし、金利上昇 → 住宅ローン返済負担と国内消費への逆風
- 原油・エネルギー高 → 豪州の交易条件には支援要因となり得る一方、国内インフレには上昇圧力
- 豪ドルが0.70ドルを明確に上回れるかは、米ドルの方向、商品価格、RBAの政策見通しに左右される

# 投資家向けチェックポイント

1. **ブレント原油が110ドルを再び上回るか**：イラン・米国協議の進展、米国中間選挙に向けた緊張の高まりを確認する。  
2. **10年OAT-Bundスプレッドが154～159bpへ拡大するか**：フランスの抗議活動、軍投入、財政運営への市場反応を監視する。  
3. **フランス問題が銀行株・ユーロ・周辺国債へ波及するか**：現時点では限定的とされる波及が広がるかが重要。  
4. **米10年国債利回りが5%台で定着するか**：債券の投資妙味と、グロース株のバリュエーション圧力の両面を確認する。  
5. **米国の住宅指標と消費関連データ**：住宅ローン負担の増加が、貯蓄取り崩しから消費減速へ移行しているかを見る。  
6. **SpaceX、MetaなどAI関連企業の発表**：AI投資が実際の売上・利益成長につながっているか、期待との乖離を確認する。  
7. **ドイツZEWや欧州のインフレ指標**：エネルギー高が景況感とECBの政策見通しに与える影響を追う。  
8. **英国の賃金と11月初旬のBoE会合**：賃金上昇が続けば、利上げまたは高金利長期化がポンド・英国債に影響する。  
9. **豪ドルの0.70米ドル近辺での定着**：米ドル動向、豪州10年債利回り、商品価格、RBA見通しを組み合わせて判断する。  
10. **日本・米国の国債入札需要**：高利回りを背景にした債券回帰が続くか、株式から債券への資金シフトが進むかを確認する。
